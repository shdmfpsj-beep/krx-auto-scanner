## 실제 재선별 검증 범위
- 2026-11-11 원본 KRX 2,769 → 분석 가능한 1,988 → 기술 후보 149 → 가격 범위 생성 102 → 연구 위험 필터 통과 30.
- 이 중 모멘텀 개선·유동성·재무 관찰과 매수 가능 범위 조건을 **함께** 만족한 종목은 삼성E&A와 지어소프트 **2종목**. 149개 전체 후보 진단 원본 `all149_range_diagnostics.json`을 사용한다.
- 기존 `watch_top2`는 선정 당시 강세·기업 관찰 기록으로만 보존한다.

## 인증과 운영 보호
이 결과는 기존 저장된 **11/11 가격**과 **11/12 당시 이용한 사후 재무 API 관찰**을 재조합한 **회고적 연구 결과**다. 투자 당시 확인 가능했던 재무 원문 PIT는 0건이며, KRX 정규장 전용 거래량·가격 인증도 미완료다. 따라서 미래 정보를 모르는 상태에서 11/11 장 종료 즉시 같은 순위를 만들 수 있었다고 주장하지 않는다.

**실전 BUY 승인 0 / 현행 운영 CASH / 텔레그램 실발송 0.** 기존 원장·운영 main·과거 신호와 원본 영수증 불변. 배포 검증 전에는 Draft PR 유지.
