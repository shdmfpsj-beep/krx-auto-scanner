# V4 일별 연결 보완 — 운영 승격 없음

PR108의 가격·필터 연구 결과를 바꾸지 않고 실제 날짜를 받는 등록 원본 어댑터와 불변 전방 기록 연결을 추가한다. 기존 main·오전 일정·A/B 신호·원본 손절·영수증은 변경하지 않는다. 실제 주문과 Telegram 송신은0이다.

## 구현

- `load_dataset(..., asof=...)`는 등록된 해당 날짜의 원본 시장·패널·분류·이력·기술 후보 수를 검사한다. 기본 Nov11 재현과 2,769/1,988/149/50/4 기준 검사는 유지한다. 새 날짜의 종목 수를149로 고정하지 않는다.
- `c3_range_daily_v4.py`는 기존 V4 구조 계산·종목 순서·위험 가정을 재사용한다. 등록 커밋, 원본 실행번호, 현재 호출 실행번호, 시장/의사결정 해시, 공식-캐시 정합성 증거가 필요하다. 데이터 미수집을 후보0개로 처리하지 않는다.
- 실제 전방 등록은 직전 거래일 자료가 준비된 다음 세션 개장 전에만 허용한다. 오래된 날짜·장 시작 후 사후 신호·미래 수집 시각·누락된 등록 증거를 거부한다. 과거 재현은 결정/관찰/성과 파일을 쓰지 않는다.
- 최종 후보0개인 날도 성공적으로 분석됐다면 일별 판단을 불변 저장할 수 있다. WATCH에는 미확인 매수 범위나 손절을 만들지 않는다. 동일 모델·날짜 재시도는 최초 원본을 재사용하며 가격·손절·입력 변경은 충돌로 중단한다.
- 기존 `update_existing`을 호출해5/10/20 거래일 결과를 추가한다. 미래는PENDING, 기업행위·정지·누락은미검증이다. 상단·중앙·하단은 독립 연구 시나리오이며 주문 횟수를 강제하지 않는다.
- 기존 미국·글로벌 수집과 국내 시장 분석을 재사용한다. 기준 시각을 가진 매크로 입력이 없으면UNAVAILABLE로 남긴다. 실제 실행에서는 당시 수집 시각을 보존한다.
- CASH 카드의 고정 ‘11월11일’을 제거하고 실제 가격일·과거 재현/전일장 관찰 상태를 표시한다. 디자인과 가격 산정 규칙은 바꾸지 않는다.

## 재사용 호출 경로

`.github/workflows/c3_range_daily_adapter_v4.yml`은 **workflow_call 전용**이며 새 cron이나 자동 실전 전송을 만들지 않는다.

승인된 아침 호출자가 실제 공식 정합성 증거와 원본 등록을 완료한 뒤 같은 실행에서 다음 네 입력을 전달해야 한다.

1. `research_code_sha`: 검증한 V4 코드의 정확한40자리 커밋. 호출자의 main 커밋을 연구 코드로 잘못 체크아웃하지 않는다.
2. `registered_state_sha`: 원본 등록을 보존한 정확한 Git 커밋
3. `registration_proof`: PR101 방식의 완료 등록 증거 JSON
4. `official_source_proof`: 해당 날짜 공식-캐시 일치 증거 JSON

공식 조회 실패나 원본 등록 지연이면 호출하지 않는다. 어댑터도 다시 검증한다. 승인 엔진은 `54e7120b01966930e176d431e85b679347210c41`로 고정한다. 실제 회사 자료는 기존 DART 조회기를 사용하고 원문 PIT 인증으로 승격하지 않는다.

관찰·성과 파일만 별도 `research/c3-range-v4-observations` 브랜치의 `reports/c3_range_forward_v4/`에 append-only로 보존하도록 구현했다. 기존 파일이 다르면 덮어쓰지 않고 실패하며 main/원본 신호 경로를 stage하지 않는다. 최초 전방 실행 전에는 이 저장 브랜치를 새로 만들지 않는다.

**운영 main 호출자는 변경하지 않았다. 따라서 이 재사용 어댑터의 매일 자동 운영 배포 완료를 주장하지 않는다.** 호출자는 향후 검토 시 연구 코드의 정확한 커밋을 사용하고 관찰 보존 job에 필요한 `contents: write`를 명시해야 한다. 실전 전송 경로와 연결되지 않는다.

## 이번 실제 확인 범위

연구 push 실행에서 전체 회귀 테스트, 실제11/11 원본을 이용한 일반 날짜 어댑터 재현, PNG 생성, 잘못된 전방 등록 차단, 최신 완료일 공식 조회, 기존 무료 증권사 연결 점검, 보호 해시 비교를 수행한다. 신규 미래 결과를 기다린 것처럼 만들지 않는다.

새 날짜 허용·중복/충돌·개장 후 차단·5/10/20 성숙 전환 테스트의 가격과 날짜 경로는 **가상 fixture**다. 이를 실제 신규 거래일 분석이나 투자 성과로 보고하지 않는다. 실제 원본 재현과 가상 안전 테스트 결과는 별도 JSON/로그로 남긴다.
