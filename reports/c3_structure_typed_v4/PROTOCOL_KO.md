# 구조 유형별 범위·손절 V4 — 실행 전 연구 규약

기준 PR107 75f0c2987c6b58ac914af17b290e6e2af590bbe8. 운영 main·원본 신호·가격·손절·Telegram 영수증·일정은 변경하지 않는다. 사용자 주문 횟수·수량은 자율이다. 실주문·실제 Telegram 송신은0이다.

기존 V3는 모든 구조에 두 번의 접촉을 요구한 것이 아니다. 확정 피벗은 원래 하나로도 확인했다. 빠진 부분은 첫 눌림·완료된 돌파 재지지 자체에 맞는 확인 경로였다. 기존 HMA60 전환·phase/PR104 first_pullback_context를 재사용하며 이미 완료된 첫 재상승 이후의 두 번째 재상승을 첫 눌림으로 재명명하지 않는다. 피벗은 확인 이후 봉과 지지 유지, 돌파 재지지는 실제 돌파·기존1.2배 거래량·모든 후속 저점과 종가의 지지 유지로 확인한다. 원래 MA 접촉만으로 새 구조를 확정하지 않는다.

손절은 먼저 구조 유형별 전체 무효화 저점에서 계산한다. 첫 눌림은 해당 전체 조정 구간 최저가, 피벗은 확인 저점, 재지지는 돌파 이후 모든 봉의 최저가다. 기존0.25ATR 바닥 완충과 직전20봉 관측 하단꼬리 중앙값 중 큰 값을 사용한다. 손익비를 보고 손절을 올리지 않는다. 정상 변동을 참고한 가정이며 불필요 손절 확률이나 최대 손실을 보장하지 않는다.

지지 범위는 확인 저점 또는 기존 MA/돌파 지지와 기존0.2ATR 허용폭으로 만든다. 하단은 구조 무효화 저점보다 아래로 추가하지 않는다. 위험8%·비용반영RR1.5로 상단을 제한하되 손절·저항은 먼저 동결한다. 모든 호가의 위험·RR를 검사한다.

거리1ATR/8%의 숫자를 늘리지 않는다. 다만 이를 가격 구간을 잘라내는 하한이 아니라 가장 가까운 유효 범위 상단의 접근성 검사로 분리한다. 범위 전체가 멀면 WAIT/PASS다. 확인된 구조 안의 연속 구간은 보존하고 하단의 거리 초과를 숨기지 않는다. 이 의미 변경은 미승인 독립 연구 가정이며 기존 V3 통과라고 표현하지 않는다. 좁더라도 구조적으로 확인된 유효 구간은 NARROW_BUT_STRUCTURALLY_VALID로 구분한다. 새로 근거 없는 가격대를 더하지 않는다.

재무는 사후 API 관찰과 원문 PIT를 구분하며 기업/RS/유동성 필터의 임계값을 변경하지 않는다. 149개 각각의 독립 탈락·교집합·배타 조합·순차 필터를 모두 보존한다. 데이터 인증 보류·시장 약세·연구조건 실패·과도한 배제 가능성을 분리한다.

추가 과거 검토는 이미 보존된 자료의 기준일 전67/45/23번째 세션 세 개로 사전 고정한다. 전체85일 백테스트를 다시 하지 않는다. 세 코호트는22세션씩 떨어지며 동일 날짜/종목 중복은 한 건이다. 당시 가격만 사용하고 사후 재무·미국 자료를 과거 필터로 넣지 않는다. 현재 유니버스 조건·과거 연구 재사용 편향이 있어 독립 검증이라 주장하지 않는다. 탈락 뒤 상승은 관찰한 종가 변화이며 실제 매수 수익과 구분한다. 상/중/하 독립 가격·유효1/2/3·5/10/20 결과는 동일 비용/갭/손절우선/공통 완숙 시계를 쓴다. 미래 경로는 PENDING, 누락·기업행위·거래정지는 평가 불가다.

삼성E&A·지어소프트를 반드시 통과시키거나 CASH를 고정하지 않는다. 카드 디자인은 기존 밝은 표준을 유지하고 근거의 가격·날짜만 구체화한다. 실제 전체 실행과 산출물 검증 뒤 결과를 보존하며 새 모델의 우월성을 보장하지 않는다.

실행 후 집계 정확성 보완: 범위가 있는 표본만의 평균은 두 모델 비교에 사용하지 않는다. 같은 종목·날짜·공통23거래일 완숙/가격연속성 표본에서 범위 없음도 현금0으로 포함하는 짝지은 기대값을 별도로 계산한다. 과거 재무 PIT 미확보는 기업 부실이 아니라 UNKNOWN이다.

구조 범위 보완: HMA60 신규 전환뿐 아니라 이미 성립한 MA20>MA60 상승 추세의 첫20일 고점 돌파 후 첫 눌림도 검사한다. 기존 돌파 거래량1.2·눌림0.25ATR·확장0.8ATR·조정 거래량1.5 조건을 재사용한다. 앞선 완성 재상승이 있으면 새 첫 눌림으로 부르지 않는다. 이 추가 경로는 수익률에 맞춘 조정이 아니라 '이미 상승 추세인 첫 눌림'의 누락된 적용 범위 보완이며, 과거 표본 날짜·수치 기준은 변경하지 않았다.
