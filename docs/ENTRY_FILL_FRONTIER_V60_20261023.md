## 손익비 계산 오류 정정: 옛 84개 2R은 틀린 목표 전제

v5.8/기존 v5.9에서 **2차 매수가를 낮추면서 목표가는 1차 가격 기준의 저항**을 그대로 사용한 문제가 있었다. 예컨대 1차는 11,000원, 2차는 10,000원이면 10,100원의 기존 매물대가 있을 수 있는데, 1차 기준 11,200원 저항으로 2차 기대수익을 계산하면 낮은 저항을 건너뛴다.

- 구형 v5.9(첫 가격 기준 저항 그대로): **2R 이상 84개, 가상 체결 1개**. 이 수치는 **폐기**.
- 정정된 v5.9(각 가격의 과거 60개 완료 일봉 중 바로 위 고가를 새로 적용): **2R 이상 1개, 가상 체결 0개**.
- 신규 v6.0(가격별 가까운 저항 재평가에 더해 **최대 2ATR 현실적 거리와 지지 확인 정책 적용**): **2R·구조요건 모두 통과 0개**.

정정 후에도 생기는 2R 가설은 편향된 과거 표본이며, 독립 정규장 시세 확인·최종 80/100점 검증을 통과하지 않은 **매수 미승인 연구결과**다.

## 구현한 고정가격 실험

1. **손절 우선:** 신호일에 이미 확인된 일봉 구조피벗과 ATR 완충 사용, 미래 저점을 손절로 역산하지 않음.
2. **동일 신호 강제 페어링:** 196개 신호 각각에 1차·2차·0.5ATR·1ATR·2R 경계가격을 적용. 중복/빠진 종목·시나리오, 거래일 불일치를 차단.
3. **후행정보 제거:** 후보 가격, 60일 저항, 비용 후 손익비 계산에는 **신호일 종료 전 완료된 데이터만** 사용. 5~7일 뒤 봉은 *체결 여부와 가상 결과 확인*에만 사용.
4. **2차 대체 진입:** 1차 미체결인 경우 하나의 가격을 선택한다는 가정. 1차 체결 이후 2차를 자동으로 추가하는 수익곡선은 만들지 않음.
5. **목표도 타점별 재산출:** 2차에 기존 1차 목표를 복사하지 않음. 과거 완료 봉에서 목표가보다 바로 위에 있는 작은 저항도 보수적 가격장벽으로 처리.
6. **거래비용:** 왕복 비용 0.5%를 매수·매도 양쪽에 반영. 장중 목표/손절 순서 미상이면 손절 우선, 미체결이면 해당 시나리오의 투자 수익은 관측되지 않은 것으로 처리.
7. **기회비용:** 지정가 미체결 후 5일 내 +3% 상승했던 사례 수를 별도 집계. 다만 원래 해당 종목을 무조건 살 수 있었던 것은 아니므로 **실제 포기한 확정 수익으로 표기하지 않음**.
8. **실제 장중·정규장 검증 실패:** 종가 59/81개 충돌·장후 데이터 혼입 가능성과 당시 생존한 전체 KRX 종목 정보 미복구. **실전 주문 신호 생성 금지**.
