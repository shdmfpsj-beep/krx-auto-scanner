# 강현AI PRO · C3 V5 상승지속×실제 매수기회 연구 — 2026-11-07

> **결론: 연구 코드 실행 성공. 신규 추세 게이트·가격 적응형·위험형 모두 일관된 수익 개선 미입증. 운영 규칙 변경·새 알림·자동 주문 없음.**

## 1. 고정 가설과 연구 설계

원본 v6 **B DAILY TOP2 선정 자체를 한 건도 바꾸지 않고** 기존 v7 지지구간의 `V2_HIGH` 매수가·손절가·R1과 동일한 매수-청산 가격·비용을 비교한다. 새로운 후보를 사후에 다시 고르지 않는다.

| 방식 | 전일에 확정된 주문 방식 |
|---|---|
| V2_HIGH | 기존 고정 매수구간 상단, 익일 하루 유효한 resting 지정가 (대조군) |
| V4_MIDPOINT | 기존 상·하단 중간 지정가 (두 번째 대조군) |
| V5_TREND_GATE_HIGH | **전일 기준 60일 상승추세 TRUE + 20일 대비 최근 5일 거래대금 비율 ≥1**일 때만 기존 V2 상단 주문, 아니면 CASH |
| V5_TREND_ADAPTIVE | 위 추세 충족이면 기존 높은 지정가를 유지, 아니면 기존 매수구간 중간값 사용 |
| V5_RISK_AWARE | 전일 손절가·첫 저항으로 비용 차감 R1 손익비 ≥1, 지정가-손절가 위험 ≤12%, R1 순이익 여유 ≥1%가 되면 상단, 아니면 중간값; 둘 다 안 되면 CASH |

V5는 이미 B 후보 선별에 포함된 **상대강도 20일 양수 + 5일 가속도 양수**를 또 필터로 넣지 않고, 추가적인 전일 `trend60`와 `turnover_ratio`가 유용한지 검증했다. 모든 지정가는 다음 거래일 시가·고가·저가·종가를 읽기 전에 확정한다. 미래 봉은 사후 성과 **라벨**, 모형 주문 체결·청산 검증에만 사용한다.

- V2 `entry()`와 `exit_model()` 원래 규칙 재사용, 지정가 기준 체결 시가 개선 가능. 장중 지정가보다 한 틱 아래까지 가격 통과는 **가상 체결 가정일 뿐 호가대기열 증빙 없음**.
- 선제적으로 낸 resting 매수 주문이 손절 아래로 갭하락 출발하면 손절 기준을 이유로 소급 취소하지 않고 **위험한 실제 주문의 모형 손실로 포함**한다.
- 종가 손절 이탈 또는 정해진 5/10/20거래일 관찰 종료 후 **다음 시가 청산**, 수수료/슬리피지 비용 반영.
- 유효 미체결·거부·계좌 미진입은 **각 선정 기회당 현금 0%**로 포함하며 실제 체결 거래의 평균 손익과 별도로 보고. 이 값은 다중 종목 실계좌 수익률이 아니다.
- 미래 5/10/20일 종가 변화와 시장지수 초과수익은 **상승 지속 확인용 사후 라벨**, 이를 매수시점에 알고 있었다고 주장하지 않는다.
- 개발 구간에서는 최종 청산 시점도 **2026-03-31 이전**이어야 하며, 검증 구간은 `2026-05-01` 이후 원래 선정 일자만 포함. 종목별 20거래일 비중복 결과도 함께 공개한다.

### "오른 종목을 놓친 비용"을 같이 계산

동일한 10일 44개 기회에서 실제 주문 체결과 별도로 **가정상 첫날 시가에 1회 매수하여 공통 다음 시가에 청산**하면 비용 차감 수익인 경우가 총 **16건**. 이는 브로커 체결 가능한 매수 기회가 증명되었다는 뜻이 아닌 *기회비용 참조 라벨*이다.

**가장 중요한 V5 결론:** 엄격한 추세·손절여유 필터는 매수할 수 있는 종목 수를 더 줄이면서 미래 상승 기회를 놓칠 수 있다. 이 표본에서는 상승 지속성의 유의미한 예측 우위가 확인되지 않았다.
