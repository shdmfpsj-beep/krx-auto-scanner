감사 API가 다른 접수번호를 반환하면 목록에서 검증된 동일 본문 또는 관련 첨부 정정만 인정한다. 이 관계 확인은 첨부 내용 검증을 대신하지 않는다. 공식 DART 열람 페이지 수집 경로도 추가했지만 첨부 내용이 검증된 것으로 처리하거나 자동 PASS 근거로 사용하지 않는다.

## 실제 재무 정규화

- 표준 ID와 기존 확장 계정 검사를 유지하고, 원문 주석에서 부족한 차입 총액·정식 손익상 이자비용·감사 근거를 보완했다.
- 원문 접수번호/기업고유번호/회계연도/재무제표 범위/원·천원·백만원을 확인하고 **동일 XBRL 자산·부채·자본**과 대조한 뒤 수치 사용을 허용한다.
- 차입금은 완결된 재무활동 부채 변동표의 기초+현금+비현금=기말 및 전체 합계, 또는 부채·자본 기준값이 일치하는 명시적 자본관리 차입 총액을 사용한다. 리스·임대보증금·미지급배당금을 차입금에 더하지 않는다.
- 미분류 항목, 합계 부재, 움직임 불일치, 직접 계정과의 모순, 부채 총계 초과는 사용하지 않는다. 누락 계정을 0으로 대체하지 않는다.
- 윈스테크넷의 차입금 0은 **전체 재무활동 부채 변동표의 모든 행과 합계가 검증된 공시 단위상 0**이다. API 계정 부재로 만든 0이 아니다. 에스원은 동일 수준의 총액 근거가 없어 0으로 처리하지 않았다.
- 이자비용은 손익 금융비용 주석의 명시적 이자비용 구성항목을 구분해 전체 금융비용 소계와 대조한다. 금융원가 총액·현금흐름 조정액을 이자비용으로 대체하지 않는다. 아모레는 이자비용 16,703백만원과 기타 이자비용 5,866백만원을 합친 **22,569백만원**이다.
- 괄호 음수·명시적 숫자 셀의 대시·rowspan/colspan·전기와 당기·반올림 정밀도를 보존한다. 감사의견은 당기 및 CFS/OFS 행을 구분하고 계속기업/강조사항의 명시적 없음도 확인한다.
- 각 수치에 종목/기업/접수번호/회계기간/공시일/CFS·OFS/계정/단위/원문 및 XBRL 해시/표 위치/합계 대조/검증 상태를 기록한다. 반올림 범위 때문에 이자보상 1배 경계가 달라지면 검토 상태로 둔다.

## 기업 오류 격리와 전체 판정

- 각 기업의 실패를 기록하고 다음 기업 심사를 계속한다.
- 명시적으로 Balanced의 `ISOLATED_ISSUER_FAILURES_V1` 정책에만 적용한다. legacy 판정 계약은 유지한다.
- 개별 기업의 공시 오류/자료 미확인은 **HOLD_FINANCIAL_UNVERIFIED**, 공유 인증·요청 제한·전체 API 장애·캐시 무결성·데이터 처리 실패는 **ERROR**다. KRX 기준자료 미완결은 **HOLD_DATA_INCOMPLETE**다.
- 전체 요청 누락, 중복/불일치 후보, 필수 검토 미완료가 있으면 정상 CASH나 TOP5를 만들지 않는다. 기술적으로 진입 불가능한 후보도 재무 미확인을 기록하며, 이번 확대 심사에서는 보수적으로 전체 HOLD한다.
- 모든 필수 심사가 완료돼 확정 탈락만 있으면 **CASH_NO_ELIGIBLE**, 재무 적격과 기존 진입 조건을 충족하면 **TOP5_READY**다.
- 실제 이번 결과는 **HOLD_FINANCIAL_UNVERIFIED**. CLI는 검토 미완료를 exit 2로 반환하므로 Actions가 failure로 표시된다. 이를 통합 성공/정상 CASH라고 보고하지 않는다.
