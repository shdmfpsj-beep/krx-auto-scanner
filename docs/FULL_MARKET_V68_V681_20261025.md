## 2. '기존 82개 후보만 재검사' 문제 해결

기존 스캐너는 10월 23일 사전 선택된 **82종목**과 120일의 서로 다른 종목별 시세를 결합했으므로, 당시 선정 편향과 수정주가/수집시간 출처 문제가 있었다. v6.8은 다음을 바꿨다.

1. **2026-10-23 정확한 해당 날짜의 KOSPI 940 + KOSDAQ 1,824 = 2,764 증권코드**에서 시작. 82종목 원본 후보 파일을 입력하지 않으며 6자 영문 혼합 종목코드도 원형대로 처리.
2. `v18/market/prices/<ticker>.csv`의 **단일 시장전체 수집경로로 160거래일 이상** 이력 확보. 기존 `get_market_ohlcv_by_date(... adjusted=True)` 종목별 회복 스캔 이력으로 바꾸지 않음.
3. 최신일 2026-10-23 일봉의 시가·고가·저가·종가·거래량·실제 거래대금 모두 **인증된 공식 KRX 일별매매정보와 동일**해야 분석 허용. KRX 전체의 두 시장 종목 세트가 다르거나 하나의 일봉 값이 틀리면 결과 생성 자체를 중단.
4. 연속 날짜·해당 거래일 및 최근 160개 완료 일봉의 유효 OHLCV 확인, 비정상 시가/고가/저가·거래량 0 등은 보간하지 않음. 마지막 120개 봉을 기록해 ATR·구조손절·MA/피벗 연구 재생이 가능하게 함.
5. 종목명에 바이오·제약·ETF·ETN·스팩·REIT·우선주 의심 신호가 있는 종목을 별도 관찰/제외. **이름만으로 보통주를 독립 확인할 수 없으므로 나머지 종목도 `instrument_type=UNKNOWN`**으로 유지해 주문 미승인.
6. 20/60/120일 추세·상대거래량·20일 돌파/눌림/반등·주·월별 추세로 예비점수 산출. **예비점수 0~85점은 최종 합격점수 80점 또는 향후 5거래일 수익확률과 무관.** 수급·재무·섹터 촉매·C3 현금 미확인인 동안 누구도 매수 승인하지 않음.
