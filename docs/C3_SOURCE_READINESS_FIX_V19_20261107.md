## 2. 22:30 보고의 'TOP2 없음' 오류 방지

- `scripts/c3_readiness_gate_v19.py`에서 결정을 **보고 자료가 조회된 시점(clock)**으로 판정한다. `source_price_asof`·`generated_at`·`analysis_completed_at`·`source_received_at`·`source_run_id`·요약본을 같은 원본으로 확인.
- 11/6 22:30에는 11/6 선정이 **23:21**에 완료되어 아직 그 시점에 발표되지 않았으므로 `RESEARCH_NOT_YET_AVAILABLE_AT_CHECK_TIME` 또는 활성 실행 시 `RESEARCH_IN_PROGRESS`; **'TOP2 0종목으로 확정' 금지**.
- 11/6 23:30 이후 등록원장/공개 보고가 완전할 때는 `FINAL_RESEARCH_TOP2_UNCERTIFIED_SESSION`으로 삼성E&A·원익홀딩스를 표기하되 **정규장 독립 인증 미완료**와 `CASH`를 함께 나타낸다.
- 날짜가 맞지 않거나 요약본 SHA/실행 ID가 다르면 **이전 거래일 TOP2로 신규 추천을 만들지 않는다**.
- 등록원장 `performance.registered_signals=4`과 후속 주말 조회의 `new_registered_signals=0`은 다른 의미. `0 신규`는 **0 TOP2**가 아니다.
- 원장 상태가 명시적으로 결재/등록되지 않았다면 `0종목 최종 확정`을 생성하지 않는다.
- 추후 공식 2,769행이 확보되어도 독립 정규장 09:00–15:30 인증이 되지 않으면 거래는 **불허**.

## 3. 자동 진단 실행 및 적용 범위

- `.github/workflows/c3_readiness_provenance_v19.yml`: 기존 알림 시간을 바꾸지 않고 **22:25 KST / 23:35 KST**, 그리고 연구 caller 실행 **완료(성공·실패 모두)**에 읽기 전용 실행한다. GitHub 크론은 정시 실행 보장이 아니며 ChatGPT 작업과 별개이다.
- CI uses contents/actions **read only**, secret `KRX_AUTH_KEY`은 KRX 요청 헤더에만 사용, Telegram 토큰 사용하지 않음. 원장·기존 연구 runner·`main`의 가상거래 장부 수정 안 함.
- 출력 `c3_readiness_gate_v19.json` 및 `c3_official_dated_recheck_v19.json`을 Actions 아티팩트로 보존. 작업 후 실제 ChatGPT 정기 보고에서는 status를 확인하며, 없다면 스스로 최신 리포트 시계와 등록 상태를 동일 기준으로 검증해야 한다.
- **보완 범위**는 데이터 원본 대조와 보고 오판 방지. 독립 정규장 가격 공급자의 신뢰성/권한과 투자전략의 미래 수익성까지 해결했다고 주장하지 않는다.
