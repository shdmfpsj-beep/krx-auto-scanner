## C. 최종 종목선정 구조

1. 기존 KRX KOSPI·KOSDAQ OHLCV 수집, 60세션·시장 최소 범위·수치 검증.
2. 기존 추세·상대강도·거래대금·과열 필터, 피벗/ATR 지지선과 호가 반올림으로 기술 강도와 진입 기회 계산. 제약·바이오 제외는 기존 명칭 필터를 유지한다.
3. 실제 가격 계약: `0 < stop < entry_low < entry_high < R1`, R1은 종가 위, R2는 있으면 R1 위. 실제 상단 위험 `(high-stop)/high*100` 1.5–5% 유지. 손익비는 참고값이며 2배 제한 없음.
4. ENTRY_READY는 종가가 유효 범위 안. NEAR_ENTRY는 종가가 상단 위이고 거리 `(close-high)/close*100 <= 2`. 아래 가격·먼 가격·무효 구조는 WATCH/탈락이며 최종 TOP5에 포함하지 않음.
5. 유효 진입 후보만 최대 30개 조회. ENTRY_READY 우선, 기존 기술 기회/강도로 조회 순서 결정. 조회 범위의 정확한 재무 커버리지와 초과 보류 수 기록. 전 시장 기술 스캔과 전 상장기업 재무 전수 검증은 동일하지 않다.
6. 기존 연간·누적분기 공시일·연결/별도 비교, 양의 자본·영업이익·부채 위험 기준으로 재무 통과 확인. 같은 진입 상태 안에서 기존 재무 /30 → 낮은 부채비율 → 진입 기회 → 기술 강도 순으로 최대 5개 선정.
7. ENTRY_READY가 있으면 ENTRY_READY 신호, NEAR_ENTRY만 있으면 WAIT_FOR_ENTRY, 모든 필요한 근거가 정상이고 최종 적격이 없으면 CASH. 자료나 계산의 불일치는 ERROR.
8. 실제 60봉과 선정 종목·이름·상태·가격·classic PNG를 검증. 수동 PR 검증은 발송하지 않음. 운영 예약/전송 제한은 기존 조건 유지. 실제 주문은 항상 사용자 직접 실행.

동일 실행에서는 공시 근거를 한 번 조회하여 재사용한다. 장기 캐시의 정정공시 무효화 기능은 새로 만들지 않았다. 30개는 API 공식 한도나 최적 수익 범위가 아니라 실행 비용을 제한하는 운영 상한이다. 과거 실행의 9개 조회는 약 45초였지만, 30개 실시간 조회의 지연/할당량은 이번에 재측정하지 않았다. 31위 이후는 보류될 수 있다.

## E. GitHub 결과와 적용 경계

작업 브랜치: `fix/c3-top5-audit-20261121`. 모든 변경은 이 통합 PR에서 검토한다. 정확한 커밋·PR·CI 실행 링크와 main 반영 상태는 PR 메타데이터와 최종 작업 보고를 기준으로 한다. 이 문서는 승인되지 않은 운영 적용이나 실제 전송을 완료했다고 선언하지 않는다.

## F. 남은 필수 과제

필수 마감은 통합 PR의 자동 검증 결과 확인과 운영 반영 여부 검토다. 추가 알고리즘 개발·성과 연구는 필요하지 않다. 반영 후에는 기존 예약 실행에서 상태와 영수증을 관찰하는 단계이며 별도 반복 테스트 전송이나 새 알람을 만들지 않는다.
