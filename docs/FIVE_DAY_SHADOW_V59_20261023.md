## 4. 모의 체결 규칙 (수익 과대평가 방지)

1. 기술신호 발생일과 다음날 주가를 섞지 않음. 모든 진입가·구조손절·목표가 생성에는 **신호일 종료까지의 완료 일봉만** 사용.
2. 1차 또는 2차 한 가지 지정가만 **다음 2거래일 동안 독립적으로** 가상 체결 심사. 두 안을 모두 실제 거래하거나, 1차 손실 후 2차 물타기하지 않음.
3. 갭 하락으로 시가가 손절 아래에 형성되면 실제보다 좋은 손절가로 가정하지 않음. 진입 전 아래 갭으로 구조가 망가지면 **진입 취소**.
4. 진입 뒤 갭 하락 시 **손절가보다 낮은 실제 시가**를 사용; 목표가 위로 갭 상승했어도 **원래 목표가로만** 청산.
5. 하루 고가·저가 양쪽에서 손절과 목표를 만졌으면 **손절이 먼저**라고 가정. 매수 지정가에 당일 저가가 닿고 목표가에도 닿은 경우 고가가 매수 전인지 모르므로 그날 목표 익절을 자동 인정하지 않음.
6. 체결 후 최대 5거래일 보유, 5번째 완료 일봉 종가로 시간청산; 왕복 수수료·체결비용 합계 0.5%를 매수/매도에 나누어 반영.
7. 2거래일 유효 주문기간 + 5거래일 보유기간이 모두 관찰된 기록만 결과에 사용. 자료가 덜 모이면 `PENDING_FULL_FORWARD_HORIZON`으로 두고 승/패를 **만들지 않음**.
8. 기술신호를 5일마다 계속 중복 발생시켜 백테스트 사례 수를 부풀리지 않도록 **해당 종목·전략별 최소 7거래일 중복 차단**.

## 5. 실제 날짜 2026-10-23 이후 미관찰 추적

v5.8 당일 패턴 신호는 `첫 눌림 0 + 재시험 1 + 추세 눌림 16 = 17건`이다. 이를 **1차/2차 대체안 별개**로 기록한 `forward_seed_v59_asof.csv` **34행**을 생성했다.

- 기준일: **2026-10-23**; 주말 10월 24~25일은 거래일이 아님.
- 해당 거래일 이후 5일 수익 결과를 관찰한 바가 없으므로 **미래 체결 0건 확인, 미래 수익률 계산 0건**. 이 0은 손실이 아니라 **아직 관찰 전**을 의미.
- 가격 출처가 여전히 독립적으로 검증되지 않아 **실제 주문승인 0건**.
- 향후 v5.8 거래일별 정상 아티팩트가 새로 만들어지면, 성공한 해당 실행번호/거래일만 추적해 그날 신호들의 `forward_seed`를 생성한다. 타 날짜 자료 혼입 시 실행 차단.
- GitHub Actions 아티팩트의 보존기간은 제한되므로, 이 기능만으로 장기간 미래 체결 성과가 자동으로 영구 저장되는 것은 아님. 5일 결과 누적은 다음 개발 단계.
