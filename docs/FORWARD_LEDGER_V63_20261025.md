## 2. 기술적으로 무엇을 고정하는가

23일의 `entry_strategy_v58_all.csv` 246행과 `entry_strategy_v58_status.json`을 확인하고 `setup=RESEARCH_TRIGGER_CONFIRMED_ASOF`인 17개 방법별 신호 각각에:

1. **1차 매수가** 및 **1차가 미체결일 때 사용하는 2차 대체 매수가**를 별도 연구 가격으로 고정. 두 가격을 동시에 주문하거나 1차 매수 후 물타기하지 않는다.
2. 신호 시점의 **일봉 확정 구조손절**을 고정.
3. **1차와 2차 목표가격을 각각 당시 완료된 과거 일봉의 가장 가까운 고가 저항으로 새로 계산**. 과거 v5.9에서 발견했던 잘못된 공동 목표가 재사용 오류를 재발시키지 않음.
4. 비용 왕복 0.5%를 반영한 1차/2차 **별도 2R 손익비**와 1/2ATR 진입 거리, 구조손절 폭을 기록. 다만 정규장 가격·일반주·당시 실측 거래대금·계좌현금·최종 80점이 검증되지 않았으므로 어떠한 매수가도 자동 승인되지 않음.
5. 제약·바이오·분류 불명 등 탈락 이유를 **목록에서 삭제하지 않고 원본 상태대로** 기록. 연구 표본의 선택적 삭제 방지.

동결 manifest는 수집시간(UTC), 당시 **정확한 v5.8·KRX recovery GitHub 실행번호**, 원본 4파일 SHA-256, 34개 신호 가격의 정규화 SHA-256을 포함한다. 개별 아티팩트가 변경됐거나 날짜가 바뀌면 검증 실패. GitHub Actions 아티팩트는 실행별 별도 업로드로 저장하고 **90일 보존**이며 영구 보관은 아니다.

### 소스 출처 검증 조건

- 각 미래 일자는 원본 Sector Evidence v18의 **성공한 정확한 GitHub run ID**, UTC 완료 시각, KOSPI/KOSDAQ 날짜별 CSV 각각의 SHA-256 및 고유 종목코드를 가진다.
- 새로운 일자는 반드시 동결 신호일보다 **나중**이어야 한다. 원본 수집 완료 시각도 **고정한 시각보다 나중**이어야 한다.
- 같은 거래일에 2개의 상충된 자료나 같은 신호일의 서로 다른 동결 목록이 발견되면 **조합/성과 계산을 차단**한다.
- 30개 이전 GitHub 실행까지 검색하고 날짜별 전체시장 CSV들을 결합한다. 갱신이 누락된 주말·휴일에는 없는 거래일을 생성하지 않는다.
- 시장 종목코드는 `005930`과 같이 숫자만 있는 코드뿐 아니라 `00104K`와 같은 영문 혼합 **6자리 원래 코드**도 보존한다. 이것이 우선주를 일반주로 매수 승인한다는 뜻은 아니다.

## 4. 중요 한계 — 아직 실전 수익률을 발표할 수 없음

- **2026-10-25는 일요일**이므로 23일 신호의 이후 거래일은 아직 들어오지 않았다. 정상적으로 10월 26일부터 완료 일봉이 축적되면 앞으로 7개 시장일의 완료를 기다린다.
- 원본 v18은 20:15 KST 수집을 시작하며, 정규장 가격(09:00–15:30)과 장후를 독립 인증한 공급원이 아니다. 과거 23일 후보 81종목 중 공급원별 종가 불일치 59건이 있었던 문제는 해결되지 않았다.
- 단순히 7개 날짜가 존재한다고 거래소 공식 휴장일 달력이 완전히 검증됐다는 뜻은 아니므로 결과는 **PROVISIONAL**로 구분한다.
- 신호가 먼저 저장됐다는 사실은 **당시 전체 KRX 보통주 PIT 선정이 검증됐다는 뜻이 아니다**. 후보 일반주 분류·실측 거래대금·재무 및 80점 점수·K100/C3 계좌 반영은 별도 과제다.
- GitHub Actions의 **90일 보존기간 이후 원본 아티팩트는 만료될 수 있다.** 90일 이상 축적하려면 별도 버전관리 저장소 기록 또는 적절한 아카이브 체계가 필요하다.
