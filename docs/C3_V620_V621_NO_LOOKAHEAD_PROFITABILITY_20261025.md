# C3 v6.20–v6.21 · 매수 수익성 검증 (2026-10-25)

## 평가 및 주의사항

v18 역사적 KRX date-only 데이터는 **정규장-only/PIT/거래 체결 검증이 없음**. 첫 날짜 2026-10-01, 마지막 10-23. 미래 5시장일 평가 시 10-19 이후 관측은 검증 불가; 예측 확률이나 거래 가능한 성과로 보고하지 않는다. 왕복 비용·슬리피지 합산 **0.65% 가정**, 동일 종목·날짜는 여러 모드에 중복될 수 있어 '모의 사례'는 포트폴리오 거래 건수 아님. 실제 `orders_enabled=False` 유지.

## v6.20: 종목 선정과 가격접촉 분리

이전 v6.15의 **외국인·기관 5일 플러스 필수** 코드가 만든 후보 458 패턴, (일자,종목) 기준 360개, v6.16의 315가지 5개 진입 연구계획에 대해 변경된 가격접촉 조건(지정가 이하 갭다운 출발·과도한 갭상승 제외)을 독립적으로 재평가.

- 315 연구계획, 281건만 미래 5시장일 관찰완료, 기존 단순 저가 가격접촉 161건, 엄격한 가격접촉(체결 아님) 126건, 모의손익 계산 가능 125건.
- 기존 지정가: 41건, 비용후 평균 **-3.608%**, 승 사례 비율 29.27%, KOSPI200 ETF 069500의 다음날 시가→매도일 종가 수익률 대비 약 **+4.697%p** (동일 시각 매매 아님, 절대수익은 손실).
- 20일 돌파 재시험: 9건, 평균 -3.683%.
- MA20 지지대기: 30건, 평균 -3.948%.
- 종가 근접: 43건, 평균 -5.020%.
- 다음날 조건 시가: 손익 계산 2건, 평균 -11.109%.
- 기존 지정가의 구조손절폭 6% 이하: **10건 +0.228%**, 7개 발생일에 불과하며, 확인 저항으로 비용후 2R 통과 접촉 **0건**. 이는 수익성 입증 아님.
- 시장 `GREEN_RESEARCH_ONLY`의 기존 지정가도 **10건 -3.184%**.
- 확인된 근처 저항까지 비용후 2R 이상인 기존 지정가의 접촉 사례 1건은 **-12.502%**, 재현 불가.

**원인 분해:** 상대수익이 (+)여도 절대수익이 (-)라면 현금을 들고 있는 쪽이 낫다. 진입 모드 개수와 단순 가격 접촉을 늘리는 것만으로는 해결되지 않음.

## v6.21: 외국인·기관 필수조건을 없애고 전시장 상대강도 선별

별도 ChatGPT 컨테이너 소급 코드 `c3_v621_fullmarket.py`로 KOSPI/KOSDAQ 시장 전체 날짜별 OHLCV를 탐색; 10/23 파일상 KOSPI 940, KOSDAQ 1,824 가격코드부터 시작. 일별 거래대금 50억원 이상·주가 2천원 이상만 연구. 15거래일 559개 규칙 신호, 날짜 중복 제거 전 240종목. 이 파일은 실제 보통주/제약·바이오 제외 규칙을 완전히 인증하지 못해 C3 실전 후보로 사용할 수 없음.

미래 5시장일 손익 완결 신호의 다음날 시가→5일차 종가 모의수익:
- RS_LEADER 348건: **-6.532%**, 양수 사례 26.15%.
- FIRST_PULLBACK_RECLAIM 103건: **-6.433%**, 양수 사례 26.21%.
- EARLY_MA20_RECOVERY 69건: **-3.108%**, 양수 사례 31.88%.
- RS_LEADER_AND_LOW_RISK 37건: **-5.975%**, 양수 사례 24.32%.

MA20 초기 회복형에서 일봉 피벗을 사용한 스톱 연구계획의 비용후 평균은 22건 **+0.043%**였으나, 중앙값 **-2.414%**, 단일 +42.573% 제외 **-1.982%**, 10% 절사평균 **-2.021%**. 날짜 클러스터 부트스트랩 임시 95% 범위 **[-3.11%,+7.41%]**로 불확실성이 큼. 따라서 **검증된 수익 우위 없음**. 단일포지션 완결 표본도 모드당 2건으로 지나치게 부족.

**v6.21을 v6.20 CI 실행 산출물이나 실전 전략으로 승격하지 말 것.** 이번 파일은 ChatGPT 컨테이너 오프라인 실험으로 별도 제공됨. v6.20 repo 연구/CI 선언은 존재하지만 GitHub Actions 신규 성공 실행을 아직 확인하지 못했으며, 독립 검증 필요.

## 향후 실험 설계

사전 고정 가설: **초기 MA20 회복 + 인접 피벗 위험이 적은 종목**을 주도 섹터 안에서 확인한 뒤, D+1 재시험 종가와 D+2 무추격 진입만 평가. 정규장-only 65~120일+ 이후 새로운 5시장일을 사용해 피벗·OHLC 순서와 저항 2R·비용 등을 재검증. 동일 신호날짜 및 동일 섹터 집중을 고려한 1종목 C3 포트폴리오, 현금 기준 성과, 상위/하위 시장 국면 분리, 제약·바이오 제외, 최근 FRED 데이터를 역사적 당시 수치로 사후 역사용하지 않기. 수익이 반복 재현되지 않으면 메인 실제매수 엔진 변경하지 않는다.
