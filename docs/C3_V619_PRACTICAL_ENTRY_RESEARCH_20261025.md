# C3 v6.19 — 실제 주문 호가/진입 가능성 연구 (2026-10-25)

> 이 기록은 2026-10-23까지 수집된 V18 'date-only' 일봉과 v6.15 후보에 대한 **과거 소급 실험**입니다. 정규장-only 데이터 완전성이 인증되지 않았고 10/26 현재가·주문 체결은 확인되지 않았습니다. 실제 매수 권고/자동주문이 아닙니다.

## 1. 고친 문제

- 이전 연구는 KRX 호가단위가 맞지 않는 소수점 지정가, 다음 거래일 저가가 지정가 이하라는 이유만으로 가격 '체결'에 가까운 가정, 시초가가 이미 지정가보다 아래에서 시작한 갭다운 주문, 과열 추격이 혼동될 수 있었습니다.
- **KRX 보통주 호가가격단위** 적용: 2,000원 미만 1원, 2,000~4,999원 5원, 5,000~19,999원 10원, 20,000~49,999원 50원, 50,000~199,999원 100원, 200,000~499,999원 500원, 500,000원 이상 1,000원. 출처: [KRX 코스닥 호가단위](https://regulation.krx.co.kr/contents/RGL/03/03020100/RGL03020100.jsp).
- 스윙 일봉 구조손절을 먼저 설정. 1차는 종가-0.20ATR, 2차는 **1차 미체결일 때만 대체** 첫 지지선·돌파 재시험 연구가. 두 가격 동시 주문·자동 물타기 아님.
- 다음 날 시초가가 지정가보다 낮은 **갭 통과**면 미체결/취소 연구, 시초가 과도한 갭상승도 추격 취소. 같은 일봉에서 손절선과 목표가가 닿으면 손절 우선. 다음날 저가만으로 실제 체결을 입증하지 않음.
- D+1에서 종가 재시험 확인 뒤 **D+2 시초가**에만 연구상 진입을 허용. D+1 일봉을 미리 알고 D+1 저가에 체결했다고 가정하지 않음.
- KRX 가격은 실주문 가능한 호가격자에 맞추되, 법적 VI/정지·스프레드·잔고·실제 09:00–15:30 호가의 유효성은 별도 인증 없으므로 BUY 승인하지 않음.
