## 판정 계약

| 후보 판정 | 근거 및 처리 |
|---|---|
| `REJECTED_FINANCIAL_RISK` | 검증된 필수 탈락 근거가 존재한다. 그 판정과 관계없는 보조 자료 부족은 확정 탈락을 취소하지 않는다. |
| `REVIEW_REQUIRED` | 적격 여부 결정에 필요한 근거가 부족하다. 자동 적격 또는 정상 CASH로 바꾸지 않는다. |
| `ERROR` | API 실패, 접수번호/기간/연결·별도/통화 불일치, 캐시 손상 또는 탈락 근거 자체의 검증 실패다. |
| `QUALIFIED` | 필요한 위험 심사를 통과한 후보만 기존 기술적 조건 및 품질 순위에 연결한다. |

확정 탈락은 원본이 검증됐다는 Boolean 하나로 결정하지 않는다. 저장한 연간·최근 재무상태표 값과 회계 항등식, 공개일·접수번호, 사업 구분, 원본 해시 등을 재확인하고 해당 탈락 조건을 다시 계산한다. 확정 탈락 후보에는 품질 점수가 없어도 된다. 원본/공시 검증이 잘못되면 ERROR이며, 거기에 부채비율 초과 표시가 있어도 정상 CASH로 숨기지 않는다.

필수 후보 중 미확인 또는 미심사가 남으면 정상 CASH를 선언하지 않는다. 기존 30개 API 심사 상한을 넘겨 미심사 후보가 남은 0종목도 정상 CASH가 아니다. 후보 판정과 전체 워크플로 상태를 각각 기록한다.

부채비율 300% 기준은 변경하지 않았다. 금융업·업종 미확인 기업에 일반 기업 부채비율을 적용해 확정 탈락시키지 않으며 별도 모델/검토를 요구한다. 비양수 자기자본, 검증된 지속 적자 및 비적정 감사의견 등 기존 중대 위험은 그대로 심사한다.

## 필수 자료와 업종 범위

- 일반 제조·자동차/부품·통신·유틸리티는 자기자본/부채, 현금흐름, 유동성 및 차입·이자상환 근거를 심사한다. 위험 판단에 필요한 자료가 없으면 REVIEW_REQUIRED다.
- 재고·매출채권의 보조 비교, CAPEX/FCF 또는 EBITDA proxy가 누락됐다는 이유만으로 정상 기업을 일괄 탈락시키지 않는다. 결측·관측 범위를 표시한다. 통신업 등의 실제 채무상환 위험을 확인할 수 없으면 통과시키지 않는다.
- 건설 PF·우발채무·미청구공사·손실충당·수주 질은 자동 확인이 부족하면 해당 기업을 보류한다. 다른 업종까지 미완성으로 처리하지 않는다.
- 금융 전용 모델과 모든 업종의 주석 자동분석은 후속 범위다. 금융기업을 일반 모델로 자동 적격 승격하지 않는다.
- 12월 결산이 아닌 연간 보고서 및 현재 누적 보고서 부재 등 기존 지원 한계는 보류 처리한다. 완전한 과거 PIT, 공식 수정주가/15:30 인증을 주장하지 않는다.

## 차입금·이자·주석의 실제 확보 범위

1. 표준 계정 ID를 우선한다. 표준 ID가 없는 기업 확장 계정은 BS/IS 구분과 정확한 계정명이 일치하고 수치가 유일할 때만 사용한다. 같은 직접 계정의 수치가 충돌하면 ERROR다.
2. 기타금융부채·금융원가·이자 지급액·CF 조정액을 각각 차입금 또는 정식 IS 이자비용으로 대체하지 않는다. CFS/OFS도 혼합하지 않는다.
3. 공식 `document.xml`과 `fnlttXbrl.xml` 경로로 한국가스공사 원문을 실제 확보했다. 원문 XML 일부는 문법 오류로 엄격 파싱이 어려웠다. XBRL은 법인 `00261285`, 연결(CFS), 2025년, KRW로 고정해 읽었다.
4. XBRL의 자산·부채·자본이 기존 전체재무제표 API 값과 일치했다. 추가 차원(부문·관계사·상품 등)이 붙은 사실은 회사 전체 차입금에 합산하지 않는다. 정식 IS 이자비용 또는 채무만기 분류는 별도 검토 상태다.
