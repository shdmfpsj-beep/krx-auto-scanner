## 다음 실행의 단일 핵심 임무: '데이터 인증 → 날짜 연결 → 실제 진입 타점 검증'

### A. 가격 진본성 및 기업행위 확인 (최우선)

1. 원본 아티팩트, 원본 SHA, 거래일별 KOSPI/KOSDAQ 자료를 다시 읽고 새로운 관측 거래일을 추가한다. 없으면 신규 자료 없음으로 정직하게 보고한다.
2. 410건 불연속 의심 사례를 종목·날짜별로 기업행위/수정주가/오류/미확인으로 분류하되 공식 근거가 없으면 미확인 처리한다.
3. 정규장 09:00~15:30 전용 가격의 독립 증빙, 거래정지, 상장폐지, 관리종목·보통주/우선주 **신호 당일** 분류를 검증한다. 과거 일자 API 재조회가 원본 시점 자료임을 보장하지 않음을 명시한다.
4. 확정 가능 건만 다음 분석에 투입하고 인증 전 실전 매매 성과를 확정하지 않는다.

### B. 상대강도·수급·재무 PIT 연결

1. 코스피/코스닥 공식 지수 데이터 접근 권한(현재 HTTP 401)을 확인하고, 허용된 대체 **공식 자료**가 실제 있을 때만 날짜별 지수 21종가 창을 연결한다.
2. 외국인·기관 **개별 종목** 순매수, 거래대금, 수집시각, 데이터 공급자와 원본 파일 SHA를 기록한다. 개인수급·섹터 ETF 수급을 외인/기관 실측으로 대체하지 않는다.
3. OpenDART 재무는 원문 접수번호, 접수일, 이용 가능 거래일, 당기/전기 매출액·영업이익·이익률·부채비율, 정정공시 여부, 원본 숫자 출처를 교차 확인한다. 미확인 재무로 '우량 기업'이라고 판정하지 않는다.
4. 공시시점 이후 이미 공개된 자료만 각 날짜의 종목에 연결하고 전후 매칭 수(가격 129, 잠정 재무 14, 엄격 PIT 0 등)를 표로 제시한다.
5. 섹터와 시장 국면 구분은 당시 확인된 구성종목과 지수 데이터가 있을 경우에만 실시한다. 구성종목 PIT가 없으면 해당 검증을 BLOCKED로 표시한다.

### C. TOP2 예측력과 실제 매수 타점의 분리 검증

1. PR #87 기존 78건을 고정하고 2026-09-16 이후 신규 표본을 완전히 분리한다. 신규 결과를 보고 과거 규칙을 재조정한 뒤 같은 신규 표본으로 재검증하지 않는다.
2. 5·10일 강세와 20일 상승 지속성을 별도로 평가하되 미관측 검열, 20일 종목 중복, 확정일 전 학습 누설을 통제한다.
3. 기술지표 5개와 검증된 가격·재무·수급만 비교하고 AUC, 신뢰구간, 상승률, 평균/중앙값 수익률, MFE·MAE, 시장/섹터 분해, 검증 표본 수를 공개한다.
4. **종목선정 수익률과 진입 가능성을 분리**: 실제 선정일 등록 매수 범위, 다음 장 이후 유효기간, 지정가 도달, 미체결 PASS, 갭하락, 동일봉 손절/목표 순서 불확실성, 거래비용을 고려한다. 일봉 고저가 겹침은 체결 증명이 아니다.
5. 신규 자료가 충분하지 않거나 확정 15:30 가격/기업행위가 없으면 수익률 개선과 새 승격 조건은 보류한다.
