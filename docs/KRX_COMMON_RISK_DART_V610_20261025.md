## 2. KRX 공식 종목기본정보: 인증키 재사용

기존 GitHub Secret **KRX_AUTH_KEY**로 KRX 공식 일별매매정보가 아닌 **종목기본정보 API 2개**를 별도 호출했다.

- 유가증권: https://data-dbg.krx.co.kr/svc/apis/sto/stk_isu_base_info?basDd=20261023
- 코스닥: https://data-dbg.krx.co.kr/svc/apis/sto/ksq_isu_base_info?basDd=20261023

반환 데이터의 **ISU_SRT_CD**(단축코드)를 v6.8 6자리 종목코드와 결합했다. **ISU_CD**는 표준 ISIN이므로 앞/뒤를 임의 제거해 종목코드를 만들어서는 안 된다. KRX 응답의 증권구분 **SECUGRP_NM = 주권**, 주식종류 **KIND_STKCERT_TP_NM = 보통주** 두 가지가 모두 명시된 경우에만 기본정보상 보통주로 표시했다.

| 종목분류 검증 | 실제 결과 |
|---|---:|
| KRX 종목기본정보 확보 | **2,764건** |
| 기존 v6.8 기초 기술후보 | **52종목** |
| 두 공식 유형 필드에서 보통주 확인 | **50종목** |
| 증권유형이 주권·보통주 두 조건을 동시에 못 채움 | **2종목** |

보통주로 분류하지 않은 사례는 **로스웰(900260: 외국주권)**, **고스트스튜디오(950190: 주식예탁증권)**이다. 이들 종목에 보통주란 주식종류명이 있더라도 공식 증권구분 자체가 일반 주권과 달랐으므로 무조건 포함시키지 않았다.

**주의:** KRX 기본정보의 **SECT_TP_NM(소속부)**는 정식 업종/산업분류 코드가 아니다. 기본정보의 기준일 요청은 기록했지만 KRX가 당시 정확히 언제 데이터를 공개했는지 또는 독립 PIT 역사판별까지 확인된 것은 아니다. 따라서 KRX 공식 보통주 유형 확인을 **실시간 거래 승인**과 혼동하면 안 된다.

## 3. 강세 수급 분야·구조손절·1·2차 가격을 순서대로 확인

v6.9 연구 분류에서 **건설**, **보험** 두 개 ETF 구성종목 섹터 대용지표만 강세 요건을 충족했다. 세 번째 **콘텐츠**는 순매수가 양수여도 RS가 음수이고 종목 확산 부족으로 단순 관찰이다.

v6.10은 v6.8 52개 기술 후보 / 156개 패턴평가, v6.9 정확한 투자자 5일 순매수, v6.8.1 거래대금 **C3 50억 이상**, 공식 KRX 보통주 필드를 모두 연결한다. 기술패턴 이후 가격은 **daily structure stop → first limit → second alternate limit → nearest historical resistance → cost-adjusted 2R** 순서로 검증한다.

- 2차 가격은 **1차 매수가 체결되지 않은 경우의 대체 지정가**이지 같은 포지션에 추가 물타기하는 것이 아니다.
- 확인된 일봉 구조손절가가 1차 매수가보다 낮아야 하며, 2차 대체가격도 손절가 위·1차 매수가 아래여야 한다.
- 1차/2차 둘 다 거래비용 반영 **최소 2R**, 1차 구조손실률 **2~12%**라는 연구용 가격 기하 조건을 만족해야 한다.
- 기술 패턴이 확정되지 않았으면 임의 가격으로 손익비를 꾸미지 않는다.
- 결과는 최종 보통주 PIT/공식 정규장/재무/최소 80점 검증 전까지 전부 주문 미승인.

| 단계 (2026-10-23) | 결과 |
|---|---:|
| 52개 종목 중 패턴을 하나 이상 확인한 종목 | **11** |
| 방법별 기술패턴 신호 | **12** |
| 전체 52개 중 1·2차 둘 다 2R 가격구조 확인 | **0** |
| 건설·보험 강세섹터 + C3 유동성 + 5일 외국인/기관 합산 순매수 | **삼성E&A 1종목** |
| 그 1종목의 확정 기술패턴 | **0** |
| 그 1종목의 두 대체가격 모두 2R | **0** |
| 최종 80점 통과 / 실제 신규매수 승인 | **0** |

삼성E&A(028050)는 공식 KRX 기본정보 **주권·보통주**가 확인됐다. 그러나 단기 진입 패턴이 3방법 모두 없고, 공식 15:30 정규장-only 가격 및 최종 80점도 확인되지 않아 **CASH**. 실전 매수가·손절가·5일 상승확률을 제시하지 않았다.

## 4. 기존 OpenDART 공시 16,790건을 시간적으로 안전하게 쓰기

v18은 실제 OpenDART 데이터 **16,790건**이 수집돼 있다. 그러나 2026-08-24~2026-10-23 각 공시에는 **접수일자(receipt_date)만** 있고 정확한 최초 발표시각은 없다. 뉴스 아카이브는 키 미비로 **MISSING_KEYS**이고 실적 증가액·계약수주 금액 등 내용 파싱은 없다.

v6.10.1은 **2026-10-23 당일 공시**를 당일 특정 시각에 이미 알려진 호재처럼 소급하지 않는다. 전일 이전 최근 30일의 공시 제목만 별도 분리한다.

| DART 검증 지표 | 결과 |
|---|---:|
| 원본 날짜형 OpenDART 접수 | **16,790건** |
| 52 기술예비후보에 관련된 전일 이전 30일 접수 | **79건** |
| 당일 공시이면서 공개시각 미확인으로 제외 | **6건** |
| 최근 30일 공시가 1건 이상 있는 후보 | **28종목** |
| 강세섹터 수급연구 1종목의 실적/재무 관련 공시 제목 | **3건** |

삼성E&A(028050)는 전일 이전 30일간 **공시 접수 11건**, 그중 **실적/재무 관련 제목 3건**, 공급계약/수주 관련 **제목 2건**을 확인했다. **2026-10-22**에는 연결 잠정실적·자기주식 취득·주식소각 관련 공시 제목이 포함된다.

**중요:** '잠정실적 공시 존재'는 실적이 좋아졌다는 뜻이 아니다. 증감액/전년동기비/영업이익률/부채·현금/수주 잔액 등을 읽고 확인하지 않았으므로 **성장성 합격/신규 실적 호재/최종 80점 인증을 일절 하지 않는다**. 정정 공시가 포함돼 있어 원문과 최신 정정 본문을 비교하기 전에는 오판 가능성이 있다.
