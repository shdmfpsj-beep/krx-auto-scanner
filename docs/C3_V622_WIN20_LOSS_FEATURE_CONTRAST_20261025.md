# C3 v6.22: +20% 5-session winners vs losing stocks (2026-10-25 research)

## 연구 질문
직전 정규장 일봉 종가에 이미 알 수 있었던 요소로 5거래일 이내 +20% 급등주를 분류할 수 있는가? 그렇게 분류했을 때 **실제 가상 수익률도 플러스로 바뀌는가?**

## 자료/절차
- 원본: 2026-10-23 종료된 frozen Sector Evidence v18 `market/prices/*.csv` 2,870 증권코드, `market/etf_prices/069500.csv` KOSPI200 ETF 프록시. 전체 가격원본은 **정규장-only 독립 검증 불가**, 역사적 보통주 여부/바이오 제외/회사 공시 PIT 및 조정시점 불명.
- 최소 65개 선행 일봉, 주가 >=2,000원, 당일 거래대금 >=50억원 및 앞 20거래일 평균 >=15억원, ATR% 0.7~12; 종목별 신호 간격 5바 이상으로 부분적 중복 제거.
- **성과라벨 = D+1 시가부터 D+5 종가까지, 왕복 비용/슬리피지 가정 0.65% 차감한 값.** `WIN20`는 >=+20%, `LOSS`는 순수익률 <0%. 장중 미래 5일 고가 +20% 도달(`MFE20`)은 실현수익 아님.
- 시간 학습: 신호일 2025-12-05~**2026-06-23**, 뒤쪽 분리 검증: **2026-07-01~10-16**. 06-24~06-30 신호는 미래 5일 손익이 7월로 넘어가므로 **embargo**해 미래 기간 누수 차단.
- 14개 설명변수: 5/20/60일 수익률, 시장 대비 5/20일 상대강도, 거래량·거래대금 20일 대비 배율, ATR%, 20일선 이격·기울기, 장중 종가위치, 시초가 갭, 20일고점 이격, 20일 변동폭. 모두 **신호일 마감 정보까지만**.
- 재현용 파이썬 및 상세 사례 CSV는 같은 사용자 대화 첨부 `C3_v622_winners_vs_losers_research.zip`에 제공. 이 연구 파일의 소급 숫자를 GitHub Actions 정규장 실거래 백테스트라 주장하지 않는다.

### 결과를 보지 않고 훈련한 LogisticRegression 시계열 외부기간 분리검증
- 고정 14개 특징 + train 분포 1%-99% winsor + 표준화 + L2 C=0.3, class_weight balanced; **이후 기간으로 파라미터 조정 안 함**.
- ROC AUC 훈련 0.6758 -> 검증 **0.5735**. 검증 AP **0.0376** vs 승자 기본 비율 **0.0304**. 재현성이 강하지 않음.
- 72개 미래 검증 시그널 날짜 중 매일 가상 Top5 (360개 신호, 실제 독립 거래/실계좌 수익 아님): ML 점수 Top5 24/360 (6.67%) 승자, **모의 순수익 -2.215%**; 거래량 Top5 25/360 (6.94%), **-2.081%**; 단기 상대강도 Top5 19/360 (5.28%), -2.441%; 고정 난수 대조 18/360 (5.0%), -1.423%.
- **주요 결론:** WIN20을 더 자주 맞힌다고 C3 1종목 실전 계좌가 수익나는 것은 아님. 희귀 급등주의 편향, 일반 종목 큰 손실, 진입/청산/계좌/호가/뉴스/PIT 미검증; 확률 수치가 보정된 실제 미래 적중확률도 아님.
