## 동일 B 선정에서 세 진입 패키지

A/B/C **선정 모델**과 아래 A/B/C **진입 패키지**는 구분한다. 후보는 선정 B로 고정했다. 공통 구조손절은 기존 2좌·2우 확인 저점과 확인 당시 고정 ATR 완충이다. 2개 자금 슬롯·지정가 1세션 유효·거래비용 매수 0.15%/매도 0.50%·각 방향 슬리피지 0.10%를 유지했다. 5/10/20개 완전 진입 세션 뒤 다음 거래 시가를 사용한다.

- A_SUPPORT_LIMIT: 기존 지지+0.25~1 고정 ATR 지정가. 6차 B_DAILY_PULLBACK의 주문·진입·완료·평균·체결률·자금손익·MDD를 모든 기간에서 정확히 재현했다.
- B_CONFIRMED_PULLBACK: 상승 마감·전일보다 높은 종가, 20→10→5일선 순서의 첫 지지 회복, 이전 5세션 같은 지지 접촉 없음. 다음 거래 시가에만 진입한다.
- C_LIMITED_BREAKOUT: 기존 20일 고점·상승봉·거래량 1.2배 돌파 확인. 다음 거래 시가에만 진입한다.
- B/C 상한은 신호 종가+현재 0.5ATR, 첫 저항이 확인되면 비용 차감 상승 여력이 양수인 가격까지다. 상한 초과 갭은 미체결이다. 첫 저항이 없으면 미확인으로 남겼다. 새로운 1R/고정 -3%/-5%/-8% 조건을 끼워 넣지 않았다.

## 구조손절 진단

지지선·손절가는 바꾸지 않았다. 20일 완료 기준 지지 지정가의 1~2 고정ATR 거리 5개는 평균 손절 거리 15.67%, 순손익 -9.08%; ≤1ATR 1개는 +22.15%여서 통계 판단 불가다. 눌림 시가 진입은 >2ATR 4개에서 평균 손절 거리 32.28%, 순손익 -26.96%; 돌파 진입은 7개 모두 >2ATR, 평균 거리 32.61%, 순손익 -17.58%였다. 체결률 개선만으로 오래된 구조저점까지의 위험이 해결되지 않았다.

손절을 당일 종가에 체결시키지 않았으며 종가 이탈 후 다음 거래 가능한 시가·갭·비용을 유지했다. 원장의 개별 실제 다음 시가와 손절선 차이, 종가 이탈 가격 대비 다음 시가 차이는 모바일 `stop_diagnostics.json`에 기록한다. 이를 보고 새 손절 임계값을 만들지 않았다. 손절 중 MFE/MAE에는 관찰기간 후속 경로가 포함되어 청산 시점까지의 실현 손익과 다르다.

## GPT 보조 선정 C와 미래 결정

TradingAgents의 공개 상승 주장/위험 반론 분리를 참고해, 당시 숫자만 담는 입력 패킷·해시·기록/실행 시각·허용 근거 키·외부자료 미사용을 검사하는 구조를 재사용했다. 상승·위험 근거 둘 다 없으면 PASS/VETO 응답을 거절한다. 출력 템플릿과 합성 테스트는 실제 모델 응답이 아니다. 실제 모델 실행 0, 유료 API 0, C 성과 미검증이다. 외부 프로그램이나 유료 연결을 도입하지 않았다.

기본 실행은 신규 결정을 등록하지 않는다. 별도 명시적 다음 실행 시각과 예상 최신 세션이 있어야 기존 변경 거절형 전방 등록기를 호출할 수 있다. 11월 6일 이후를 미리 수행하거나 사후 과거 결정으로 등록하지 않았다. 신규 완료 5/10/20 모두 0. 예약을 추가하지 않았다.
